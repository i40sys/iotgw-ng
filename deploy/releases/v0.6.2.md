# Edge Manager v0.6.2

"Boot from local disk" in the OVH netboot menu now works on UEFI gateways
whatever iPXE loaded the menu.

## Local-disk booter: `ipxe-local.efi`

- The sites' firmware iPXE loads `http://netboot.iotgw.i40sys.com/menu.ipxe`
  directly. It is too old to boot a local EFI disk (`sanboot` has no `--extra`),
  and the menu's `exit` only returned to it, which left the gateway at the
  `iPXE>` prompt.
- New release asset `ipxe-local.efi`: the same pinned iPXE 2.0.0 as the
  chainloader, embedding only `netboot/chainloader/local.ipxe`. It boots the
  local ESP that holds `\EFI\BOOT\BOOTX64.EFI` and `\startup.nsh` (written by the
  OpenWrt install, so an iPXE USB stick is never picked). If there is no such
  ESP, it tries any local EFI loader, and as a last resort exits to the firmware.
- The OVH netboot serves it (an init container downloads it from this release
  and checks the pinned SHA256), and the menu chains it for "Boot from local
  disk" on UEFI. BIOS keeps `sanboot 0x80`.
- New QEMU test: `ipxe-local.efi` boots the ESP of a GPT disk.

No changes to the platform images (frontend, backend, functions).
