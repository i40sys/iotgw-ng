# Edge Manager v0.6.4

Patch release for the user interface.

## "View Debug Log" opens one new tab only

- The button (deployment status dialog and the jobs list) opened the debug
  page in a new tab AND navigated the current tab to it. The helper used
  `window.open` and fell back to navigating the current tab when it returned
  `null` — which some browsers do even after opening the tab.
- It now opens the page through a `target="_blank"` link and never navigates
  the current tab (frontend 0.11.1, with tests).

Backend and edge functions: unchanged code, rebuilt from the tag.
