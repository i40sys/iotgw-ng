# Edge Manager v0.7.1

Node-RED can be provisioned again.

## Node-RED runs without a flows repo

- With **Node-RED** on, only the admin user and password are required.
  Node-RED starts with an empty local workspace.
- A new switch, **Load flows from a Git repo** (`nodered_flows_repo`), off by
  default, shows and requires the GitHub org. That path still needs Git access
  and a projects template that iotgw-kestra does not ship; preflight says so.
- Before, every run with Node-RED on failed in preflight
  (`.config.projects.json.j2` not vendored).

## The Node-RED editor asks for the login

- iotgw-kestra (`5ad4fd3`) ships a `settings.js` that turns the admin user
  and password into the editor login. Before, the image's stock settings
  were used: the editor on port 1880 had no login although the password was
  configured.
- Re-provisioning keeps Node-RED's data folder, so local flows survive.

## Upgrade notes

- No database migrations.
- Frontend 0.13.1, backend 1.3.1, contract 0.3.1. Edge functions: unchanged
  code, rebuilt from the tag.
