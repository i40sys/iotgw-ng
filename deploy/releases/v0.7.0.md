# Edge Manager v0.7.0

The MQTT stack no longer needs an EMQX broker, and the configuration stages
get a save button.

## The EMQX bridge is optional

- The MQTT section has a new switch, **Bridge to the IIoT EMQX broker**
  (`mqtt_bridge`), off by default. With MQTT on and the bridge off, mosquitto
  runs standalone with its local users.
- The bridge fields (IIoT broker address, bridge user and password, bridge
  topics, EMQX API URL, key and secret) show and are required only when the
  bridge is on.
- Provisioning (iotgw-kestra `b6ecbc2`) renders the bridge and calls the
  EMQX API only with the bridge on. A configuration without the switch
  bridges if it sets the IIoT broker address, as before.

## Save from the configuration stages

- The Install and Provision stages have a save button next to **Review**.
  It saves like **Save changes** and names the saved version, e.g.
  "Save changes (v3 - rc01)".

## Upgrade notes

- No database migrations. No stored configuration uses the bridge today.
- Frontend 0.13.0, backend 1.3.0, contract 0.3.0. Edge functions: unchanged
  code, rebuilt from the tag.
