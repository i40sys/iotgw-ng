# Edge Manager v0.9.0

The gateways' web UI is now the product's own console:
**IoT GW NG · Edge Console**.

## Gateway web UI (LuCI theme)

- **New theme `luci-theme-iotgw`**, a fork of the Argon theme (v3.1.2). The
  provisioning installs and selects it instead of the stock dark theme.
- **Product identity:** the menu, the login page, the browser tab and the
  footer show *IoT GW NG · Edge Console* instead of "OpenWrt". The
  gateway's hostname is shown in small type under the name. The text can be
  changed per gateway (`product_name`, `product_tagline` in
  `/etc/config/argon`).
- **Look:** iotgw-ng colours (orange, navy, paper), the Victor Mono Nerd Font,
  square industrial corners, the iotgw logo and an industrial login
  background. The **Apps** menu that the provisioning adds has its own icon.
- **No calls home:** Argon's online updater is removed, so the theme can never
  replace itself with upstream Argon from the Internet. Online wallpapers are
  off.
- The release has two new files: `luci-theme-iotgw_all.ipk` and
  `luci-theme-iotgw-SHA256SUMS`. See decision-039 and task-161.

## Developer tools

- **`just backlog`** runs only this project's backlog browser on
  `http://localhost:52175` (`status`, `stop`). Every call restarts it. It
  never touches another project's instance. `just dev` uses the same
  instance.
- **`just live-image::theme`** builds the theme package with the OpenWrt
  23.05.4 SDK. **`just live-image::theme-css`** compiles its stylesheet.

## Upgrade notes

- No database migrations. The frontend, backend, contract and edge functions
  are unchanged.
- **Provisioning (iotgw-kestra):** pin `iotgw_theme_version: v0.9.0` and the
  checksum from this release's `luci-theme-iotgw-SHA256SUMS` in
  `vars/iotgw.yml`. The next provisioning of a gateway installs the theme.
  The iotgw agent pin does not change.
- A gateway that has upstream Argon installed by hand gets it removed. Its old
  `/etc/config/argon` stays, so Argon's colours stay until that file is
  replaced.
