# Edge Manager v0.6.5

Patch release: removes an unused Kestra flow.

## `ssh-ca-renewal` flow removed

- The flow re-ran the provisioning `ssh_ca` tag on every enrolled gateway to
  renew SSH host certificates. Its schedule shipped disabled and it never ran.
- Gateways already renew their own certificate: the `iotgw` agent daemon
  re-signs it with its host key when less than 30 days remain (agent v0.3.0
  and later).
- Removed from `i40sys/iotgw-kestra` (`4f3d0a8`) and from the OVH Kestra. The
  kind safety guard and the fleet report no longer refer to it.

Backend, frontend and edge functions: unchanged code, rebuilt from the tag.
