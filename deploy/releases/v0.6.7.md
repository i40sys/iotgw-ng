# Edge Manager v0.6.7

Patch release for the user interface.

## The browser always loads the current release

- `index.html` was served without a `Cache-Control` header, so after a
  rollout a browser could keep running the previous release until a hard
  reload (after v0.6.6 the About dialog showed frontend 0.11.1 against the
  declared 0.12.0).
- `index.html` and every app route are now served with
  `Cache-Control: no-cache`; the versioned JS/CSS files keep their 30-day
  cache (frontend 0.12.1).

Backend and edge functions: unchanged code, rebuilt from the tag.
