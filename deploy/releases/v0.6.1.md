# Edge Manager v0.6.1

Patch release for the provisioning boot chain: the netboot now runs on OVH, and
*Boot from local disk* works through the iPXE chainloader.

## iPXE chainloader: "Boot from local disk" hands over to the firmware

- On UEFI the menu's `sanboot` cannot boot the local disk, so the menu exits to
  let the firmware boot its next entry (EFI Shell → `startup.nsh` → OpenWrt).
  The chainloader used to treat that return as a failure and reload the menu;
  it now exits to the firmware as well.
- New QEMU test case: a menu that exits makes the chainloader return control
  to the firmware, with no retry.
- Replace `ipxe.efi` / `undionly.kpxe` on the sites' boot servers and re-flash
  any `ipxe-usb.img` sticks with the assets of this release.

## OVH netboot (task-149)

- `netboot.iotgw.i40sys.com` serves the CI-built live image, pinned by digest,
  and the iPXE menu from the OVH cluster.
- It also serves plain HTTP (no redirect) for the sites' firmware iPXE, which
  has no HTTPS: menu, kernel and initrd over HTTP; the squashfs over HTTPS.
- y0 (`netboot.joor.net`) is now only a stub that chains the CI chainloader.

No changes to the platform images (frontend, backend, functions).
