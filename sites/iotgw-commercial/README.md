# IoT Gateway NG — commercial website

Static, multi-page and trilingual (Catalan, Spanish, English) website. No runtime
dependencies, no trackers. `dist/` is the deployable output (the hosting root in
`hosting.json`).

## Layout

| Path | Role |
|---|---|
| `src/pages/*.html` | **Source of truth, in Catalan.** One file per page. |
| `src/styles.css`, `src/app.js`, `src/assets/` | Shared CSS, JS and images/fonts. |
| `i18n/strings.ca.json` | Every translatable Catalan string, generated by `--extract`. |
| `i18n/es.json`, `i18n/en.json` | Map "Catalan string → translation". |
| `build.py` | Builds `dist/` from `src/` + `i18n/`. |
| `dist/` | Generated. **Do not edit by hand.** Committed, because it is what gets deployed. |
| `design/`, `IMPLEMENTATION.txt` | Original design assets and the change log of decisions. |

Pages: `index` (platform), `beneficis`, `funcionalitats`, `casos-exit`,
`hardware`, `desplegament`, `screenshots` (gallery; inventory and gaps in
`design/screenshots-inventory.md`).

## Build

```bash
python3 build.py --extract   # refresh i18n/strings.ca.json after editing Catalan text
python3 build.py             # build dist/; fails and lists any missing translation
```

When you change Catalan text in `src/pages/`, run `--extract`, add the new
strings to `i18n/es.json` and `i18n/en.json`, then build. Strings that the
JavaScript renders (profile tabs, comparison, outage simulation, contact
summary) live in the `IOTGW_I18N` object at the top of `src/app.js`.

## Language selection

`dist/index.html` is a small router that sends the visitor to `/ca/`, `/es/` or
`/en/`:

1. **Saved choice** — `localStorage["iotgw-lang"]`, written when the visitor
   clicks the CA · ES · EN switch in the header.
2. **IP geolocation** — the public IP comes from `https://ip.joor.net/` (falls
   back to `https://api.ipify.org/`), then `https://geoip.joor.net/<IP>`:
   Andorra and the Catalan-speaking regions of Spain (Catalonia `CT`, Balearic
   Islands `IB`, Valencian Community `VC`) → `ca`; rest of Spain and
   Spanish-speaking countries → `es`; everything else → `en`.
3. **Browser language**, then English. A 4.5 s safety timer always redirects.

Each language page carries `hreflang` alternates and its own `<html lang>`.
The router page sends the visitor's IP to the IP-echo and geolocation services;
mention it in the privacy notice if one is published.

## Preview and deploy

```bash
python3 build.py
cd dist && python3 -m http.server 12346 --bind 0.0.0.0   # http://wsl.ymbihq.local:12346/
```

All internal links are relative, so `dist/` works on any static host (the root
must serve `index.html`), also from a sub-path.

### Production: https://iotgw.industry40.systems

./publish.sh               # build, sync dist/ into the stack repo, push, deploy
./publish.sh --no-deploy   # same, without the Dockhand deploy
