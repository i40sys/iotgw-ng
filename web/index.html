COMENCEM PEL PRINCIPI / QUÈ ÉS UN IoT GATEWAY?

Les màquines tenen dades.
El gateway les connecta.

Un IoT Gateway és un equip amb programari que connecta màquines i sensors amb els sistemes informàtics de l’empresa.

S’instal·la a prop del procés. Recull, prepara i conserva dades. Alimenta aplicacions locals i envia informació als sistemes de l’empresa. Així, la planta aprofita les dades sense enviar-ho tot al núvol.

  1. 01 / LLEGIR

    Accedir a les dades.

    Obtenir valors del PLC, dels sensors o d’altres equips: temperatures, consums, comptadors o estats.

  2. 02 / PREPARAR

    Donar-los un format útil.

    Filtrar lectures, convertir unitats i adaptar protocols. Afegir el nom de la màquina i l’hora de la lectura.

  3. 03 / APROFITAR

    Convertir dades en accions.

    Alimentar una pantalla d’operari, consultar un històric o detectar una anomalia. Compartir la informació amb altres sistemes.

UN EXEMPLE SENZILL
CAS IL·LUSTRATIU

Un PLC exposa la temperatura d’un forn. Amb la integració adequada, el gateway la llegeix, la desa i alimenta un dashboard local. Si cau la connexió amb el servidor, Store and Forward conserva les dades pendents i les envia després. L’equip de planta consulta l’històric. El PLC continua controlant el forn.

Una base que creix amb el procés.

NG prepara i gestiona el gateway. Sobre aquesta base, cada projecte integra connexions, dades i aplicacions. S’hi incorporen històrics, entrega fiable, HMI, dashboards o IA segons les necessitats de planta.

El control de la màquina té el seu lloc.

El PLC i els sistemes de seguretat mantenen el control del procés i la protecció de la màquina. El gateway allotja aplicacions locals i intercanvia dades amb l’SCADA, el MES o l’ERP. Una HMI o un agent d’IA local no substitueixen el control determinista ni les funcions de seguretat.

LES PREGUNTES IMPORTANTS

Sense caixes negres.
Parlem-ne clar.

Una bona decisió comença per saber què hi ha, què encaixa i què cal validar.

És només un dispositiu físic?+

No. El valor és la combinació del programari del gateway i una plataforma central per inventariar, instal·lar, configurar i seguir les operacions. El maquinari i la seva adequació s’avaluen segons el desplegament.

Què hi ha implementat avui?+

Hem verificat una interfície funcional amb inventari de dominis, xarxes i dispositius, configuracions versionades, flux d’instal·lació d’OpenWrt, configuració de serveis i historial d’execucions amb logs. L’abast del desplegament es valida amb els requisits de la teva planta.

Funciona amb qualsevol màquina?+

La integració depèn dels protocols, dels permisos i dels connectors disponibles. Els serveis locals ofereixen una base flexible, però la compatibilitat es valida per màquina i cas d’ús. No es promet una connexió universal.

Quines aplicacions executa? Quin control manté el PLC?+

El gateway allotja HMI a mida, dashboards, analítica i agents d’IA segons el projecte i els recursos disponibles. Aquestes aplicacions utilitzen dades locals i intercanvien informació amb altres sistemes. El PLC manté el control determinista del procés. Les funcions de seguretat continuen als sistemes corresponents.

Cal utilitzar un Protectli?+

No. IoT Gateway NG és agnòstic del maquinari. El VP4651 amb coreboot és l’equip recomanat i incorpora iPXE. Altres equips requereixen validar compatibilitat, recursos i mètode d’arrencada. El Live USB continua com a alternativa.

On s’instal·la Edge Manager?+

A Internet o a les instal·lacions del client, segons el projecte. Edge Manager gestiona els gateways. Els serveis d’integració i el tractament local de dades s’executen al gateway de planta.
